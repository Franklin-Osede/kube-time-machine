kube-time-machine is installed in namespace {{ .Release.Namespace }}.

Verify the recorder:

  kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "ktm.fullname" . }}
  kubectl -n {{ .Release.Namespace }} logs deployment/{{ include "ktm.fullname" . }}

The in-cluster agent writes history to PVC {{ include "ktm.fullname" . }}-data.
The ktm CLI does not query that PVC remotely in this release. To run commands
such as:

  ktm blame deployment/<namespace>/<name>

first copy the PVC contents to a local directory and pass it with
--storage-dir. See:

  https://github.com/Franklin-Osede/kube-time-machine/blob/main/docs/install.md#querying-history-from-mode-b-cli--pvc
